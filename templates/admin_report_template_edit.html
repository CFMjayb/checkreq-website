Lines

{% if tpl.report_type == 'fund_summary' %} Each line is one row of the Fund Summary, grouped under its fund group (for example “Unrestricted Net Assets”). The account mask picks which active QuickBooks equity accounts roll up into it — {% else %} Each line is one row on Page 1. The account mask picks which QuickBooks accounts roll up into it — {% endif %} 667* (starts with 667), 4### (4 plus any three characters), 4000-4099 (a range), and several separated by commas. If two lines match the same account, the one that sorts first gets it. Click the ✕ at the left of a line to remove it: a new line disappears at once; a saved line is struck through (click ↺ to undo) and is permanently deleted when you click Save Lines. To keep a line but stop using it, untick Active instead.

{% if line_options %}
  • % charged — the share of the line's actual and budget that is charged to this report (100 = all of it). The workbook shows it next to the line's name.
  • Class — count only transactions in the classes you tick ((No class) = transactions with none). A parent class does not include its sub-classes. Put the same mask on several lines with different classes to split an account; each transaction goes to the first line, by Sort, that accepts it. QuickBooks budgets are not split by class, so a class line shows the whole account's budget and no variance.
  • Show — Sum shows only the line's total (and leaves its transactions out of the Transaction Detail tab); Detail also lists its accounts. If “Show each account under its line” is off in Options, every line shows its total only.
  • An account can't be split between two lines by percentage — use classes for that. On a whole-entity template the net is “as charged” once any line is under 100%.
  • {% from "_guide_link.html" import guide_link %}{{ guide_link("report-template-lines", "How to use report template lines") }}  Click the beacon for a one-page guide with examples.
