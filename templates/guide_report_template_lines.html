% charged, Class and Show — what each one does and how to combine them.

← Back to {{ guide.back_label }}

Where to find them

Administrative Tasks → Reports → Report Templates → open a template → Lines. Every line has an account mask (which accounts roll up into it) plus three options. The defaults leave a line exactly as it has always worked: 100%, All classes, Detail.

The three options

% charged default 100

Charge only part of a line to this report. It applies to the actual and the budget. Use a number above 0 and up to 100 (decimals are fine, such as 33.33). Leaving it blank is an error, never 100.

Class default: all classes

Count only transactions in the classes you tick. A class is always applied on top of the account mask, never on its own. Blank means every class, including transactions with no class; tick (No class) for only those. A parent class does not include its sub-classes.

Show default Detail

Detail lists the line's accounts under it. Sum shows the line's total only, and leaves its transactions out of the Transaction Detail tab.

Good to know

  • Order matters. Each transaction goes to the first line (by Sort) whose mask and class accept it. Put the specific line (a class, or a narrower mask) above the broader one, or the broader line takes everything and the specific line gets nothing. Preview Matches warns you when that happens.
  • Budgets are not split by class. A class line shows the whole account's budget and no variance. If an account sits on several lines, its budget shows once, on the first line with no class selected.
  • Percentages never split an account between two lines. Use classes for that. Each transaction's share is rounded to the cent so the lines still add up to the total.
  • If Show each account under its line is turned off in Options, every line shows its total only, whatever its Show setting.
  • Before you send anything: Preview Matches, then Save Lines, then Run Now on the Report Templates page to check the workbook.
