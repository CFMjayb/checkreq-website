Quick guide

{{ guide.title }}

Build each parish's Shared Ministry Allocation letter from the Task Force model, and check every parish on one sheet.

← Back to {{ guide.back_label }}

Where to find it

Administrative Tasks → Parish → SMA Letters. You need to be a Setup Admin or Beacon Admin at the entity you are working in (the Episcopal Diocese of Maryland).

This first part only builds and checks the letters. Nothing is emailed or posted from it. Posting, the emails to signers, signing, uploads and appeals come next.

Making a run in five steps

1. Upload the model

On SMA Letters, choose the Task Force model workbook itself (the Excel file with the Parish Data and Method A tabs) and make a run. Beacon reads the rates and each parish's figures from it, works out every letter with its own formula, and checks that it matches the model. Choose Test run first: it uses Formstack's free test merges and stamps SAMPLE on the letters.

2. Confirm the rates

The check sheet shows the rates read from the model (for example 18%, 4% and a $5,000 flat deduction). Press These are the voted rates once you have checked them. Nothing is built until you do.

3. Upload the cover letter

A PDF, the same for every parish. Beacon puts it in front of each letter. If you change it later, every letter already built needs a rebuild, and each rebuild uses one Formstack merge, so settle the cover letter before you build.

4. Send the templates

Once, Send templates puts the letter and signing-form Word templates into Formstack Documents. It uses no merges.

5. Build the letters

Build makes each parish's letter a few at a time while you watch. If you close the page halfway, open it again and press Build again: only letters not yet built are made, so nothing is built twice. Each letter uses one Formstack merge; the page shows how many are left this month. A letter that fails to build is set aside with the reason on its row, so Build does not try it again and again: fix the cause, then press Build this letter now on its page.

Reading the check sheet

  • One row per parish: the allocation, last year's and the change, who will sign, the status, anything to look at, and the latest note. Click a parish for its own page.
  • The top counts show how many parishes are ready to post, need attention (a red flag), or have warnings. The filter buttons narrow the list.
  • Download (CSV) gives the whole sheet as a spreadsheet.
  • A letter is ready when it is built and has no red flag.

What the flags mean

  • Red (blocks posting): the parish is not matched to a Beacon parish; it is inactive (closed or merged); the model's figures do not tie to Beacon's; the model shows a hand adjustment that has not been confirmed; no usable signer; or the letter is out of date after a change.
  • Amber (look at it): the model marks that parish's data as missing or incomplete; no parochial report for the latest year; figures the model left blank; a middle year that is not the average of the other two; a letter whose last build failed; a zero allocation; figures were edited here; a very long parish name.
  • Click the parish to fix it. After a fix, rebuild the letter if its figures, name or adjustment changed.

Adjustments the model carries

The model hand-adjusts a few parishes (for example a 50% reduction, or using the latest-year test when a parish has fewer than three years of data). Beacon never applies one on its own. When the model's number matches an adjustment, the parish's page offers Confirm this adjustment, and the letter then says so in words. If you would rather use the plain formula, leave it and exclude or edit the parish.

Signers

  • The rule: every parish needs at least one signer, and at least one must be clergy or the Senior Warden. A Treasurer may sign too, but not alone.
  • Signers are pre-filled from the parish roles Beacon already holds. The clergy signer is the person with the highest title in the clergy directory (Rector, Vicar or Priest-in-Charge before an interim, an associate or a deacon).
  • On a parish's page you can choose another person for a role, say a role has nobody signing, or add someone by hand. Every change is written in the parish's notes automatically. No email is sent.

Changing a figure or a name

  • The name on the letter defaults to the Beacon parish name and city. Change it on the parish's page.
  • Change a figure only to correct a mistake. Beacon asks why and records the before and after in the notes. The letter then no longer has to tie to the model.
  • A letter built before a change is marked out of date until it is rebuilt as a new version. Older versions are kept.

Notes, excluding a parish and matching

  • Notes on each parish are your tally of what has happened. Your own notes and the automatic ones (figure edits, adjustments, signer changes) appear together.
  • Exclude a parish that should not get a letter (for example one merged into another). It can be included again.
  • A model row that Beacon could not match to a parish is shown as not matched. Open it and choose the Beacon parish.
